# SeedLager

Behalte deine Sorten im Überblick, Breeder, Bestände komplett offline und ohne cloud zwang!

## Funktionen
Bestandsverwaltung: Sorte, Breeder, Typ

Mengenangabe: schnell nach jedem Grow anpassen mit Abgang Funktion

100% Lokal und Privat. Alle daten bleiben auf deinen PC
